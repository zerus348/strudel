# Strudel Studio

Live-code music with [Strudel](https://strudel.cc/) from IntelliJ (and Claude Code), playing in a browser tab.

```bash
npm install
npm run dev        # or the "Strudel: Dev Server" run configuration in IntelliJ
# open http://localhost:5173, click once, then edit songs/*.strudel and save
```
